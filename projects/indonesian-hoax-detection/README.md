# 📰 Indonesian Hoax Detection using IndoBERT, Autoencoder, and Gaussian Mixture Model

Sistem deteksi berita hoaks berbahasa Indonesia yang dikembangkan sebagai proyek **skripsi** menggunakan pendekatan **Natural Language Processing (NLP)** dan **Deep Learning**. Proyek ini menggabungkan **IndoBERT**, **Autoencoder**, dan **Gaussian Mixture Model (GMM)** untuk mengklasifikasikan berita sebagai **Hoaks** atau **Fakta**, serta dilengkapi dengan aplikasi interaktif berbasis **Streamlit**.

---

## 📌 Gambaran Proyek

Penyebaran informasi palsu di media digital menjadi tantangan yang semakin besar. Proyek ini bertujuan membangun sistem yang mampu membantu proses identifikasi berita hoaks secara otomatis melalui pemanfaatan teknologi **Natural Language Processing (NLP)**.

Selain melakukan prediksi berita, aplikasi juga menyediakan fitur pencarian berita, ekstraksi kata kunci, dan integrasi RSS News menggunakan kata kunci untuk mendukung eksplorasi informasi secara lebih mudah.

---

## 🎯 Tujuan

- Membangun model deteksi berita hoaks berbahasa Indonesia.
- Menerapkan pendekatan hybrid menggunakan **IndoBERT**, **Autoencoder**, dan **Gaussian Mixture Model (GMM)**.
- Mengembangkan aplikasi berbasis **Streamlit** sebagai media implementasi model.
- Membantu pengguna mengidentifikasi potensi berita hoaks secara lebih cepat dan mudah.

---

## ✨ Fitur

- 📰 Prediksi Berita Hoaks
- 🔍 Pencarian Berita
- 🏷️ Keyword Extraction
- 📰 RSS News
- 💻 Dashboard Interaktif berbasis Streamlit

---

## 🧠 Metodologi

Alur pengembangan sistem terdiri dari beberapa tahapan berikut:

1. Data Collection
2. Data Preprocessing
3. Tokenization menggunakan IndoBERT
4. Feature Representation
5. Feature Learning menggunakan Autoencoder
6. Clustering menggunakan Gaussian Mixture Model (GMM)
7. Hoax Classification
8. Model Evaluation
9. Deployment menggunakan Streamlit

## 🚀 Menjalankan Proyek

Clone repository

```bash
git clone https://github.com/Boekanadip/indonesian-hoax-detection-indobert.git
```

Masuk ke folder proyek

```bash
cd indonesian-hoax-detection-indobert
```

Install seluruh dependensi

```bash
pip install -r requirements.txt
```

Jalankan aplikasi

```bash
streamlit run streamlit_app.py
```
